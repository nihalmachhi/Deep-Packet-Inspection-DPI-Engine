Name the app behind every packet. Then block it.

A Python engine that reads an offline PCAP, parses Ethernet, IPv4, TCP and UDP, reads the TLS server name, HTTP Host and DNS port, and writes a filtered capture without the traffic you block.

      From capture file to filtered capture.

      Every packet goes through the same three steps. Change a rule above and the result updates at once.

      Parse

      Reads Ethernet, IPv4, TCP and UDP headers. Packets that are not IPv4 TCP or UDP are not written to the output.

      Ethernet 14 BIPv4 20 B or moreTCP 20 B or more / UDP 8 BPayload name lives here

      Extract

      Reads the server name from a TLS ClientHello on port 443 and the Host header of an HTTP request on port 80. Port 53 flows are labeled DNS.

      TLS SNI · :443HTTP Host · :80DNS · :53

      Decide

      Matches each flow against your rules. Once a flow matches, its remaining packets are dropped from the output.

      --block-app--block-ip--block-domain

      A name goes in. An app comes out.

      The engine checks 17 named apps in a fixed order. The first keyword found anywhere in the server name decides the app.

      Order matters
      YouTube is checked first and Cloudflare last. The first app with a matching keyword wins.
      No match
      A name that matches nothing is labeled HTTPS.
      No name
      Flows with no readable name fall back by port: 443 is HTTPS, 80 is HTTP, 53 is DNS.

        Your command

        What it blocks

          Block by app, address or keyword.

          Each option can be repeated. The command on the left mirrors the rules you set in the simulator.

          --block-app
          An app name such as YouTube or TikTok. The match ignores case.
          --block-ip
          A source IP address. Every flow from that address is dropped.
          --block-domain
          Any text inside the server name, compared in lower case. "tiktok" blocks www.tiktok.com.

          Same answer, more threads.

          Add --mt and the engine splits the work across load balancers and fast-path workers. --lbs and --fps set the counts, 2 each by default.

          Flow affinity
          Each flow is hashed (MD5 of its 5-tuple) so all its packets reach the same worker.

          Running in one command.

          Python 3 and nothing to install. The repository includes a sample capture.

          1. 1Filter the sample capture

            python main.py test_dpi.pcap output.pcap --block-app YouTube

            Reads test_dpi.pcap, drops the YouTube flow and writes output.pcap with a report in the terminal.

          2. 2Try the multi-threaded engine

            python main.py test_dpi.pcap output.pcap --mt --lbs 2 --fps 2

            The report also lists packets handled by each worker.

          3. 3Run the tests

            python -m unittest discover -s tests -v

          Built to teach.

          It is a computer networks project that shows how deep packet inspection works. It is not a network appliance.

          In scope

          • Offline PCAP files you supply
          • Ethernet, IPv4, TCP and UDP
          • TLS server name, HTTP Host and port 53 labeling
          • Blocking by app, source IP or domain text
          • Single-threaded and multi-threaded runs

          Out of scope

          • Live capture or intercepting traffic
          • Decrypting encrypted payloads
          • IPv6, ARP and ICMP packets, which are not written to the output
          • A ClientHello split across several packets
          • QUIC detection

          Any questions?

          Does it capture live traffic?

          No. It reads a PCAP file you give it and writes a new one. It never touches a network interface.

          Can it see inside HTTPS?

          No. It reads only the server name that a TLS client sends in the clear at the start of a connection. The rest of the traffic stays encrypted.

          Which apps does it know?

          YouTube, Google, Facebook, Instagram, WhatsApp, Twitter/X, Netflix, Amazon, Microsoft, Apple, Telegram, TikTok, Spotify, Zoom, Discord, GitHub and Cloudflare. Other names are labeled HTTPS.

          How do I add an app?

          Add it to the AppType list and to sni_to_app_type in src/types.py with the keywords that identify it.

          When should I use --mt?

          For larger captures. The report totals match the single-threaded run on the sample file.
